# Upstream attribution

This repository is an independently maintained distilled version of
[`pstack`](https://github.com/cursor/plugins/tree/main/pstack), created by
Lauren Tan and distributed under the MIT License.

The generated skills retain the upstream ideas, instructions, and bundled
resources. This `fork` changes packaging and host-specific language so the
skills conform to the open Agent Skills specification and can be consumed by
multiple compatible tools. `upstream.lock.json` identifies the exact upstream
commit and tree used for each generated revision.

This project is not affiliated with or endorsed by Cursor.
